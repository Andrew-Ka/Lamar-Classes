Part 1: Project Results
__________________________________________________________
My Project: 
	An Anki Extension solely used to make cards while browsing the web or having pdf's open in Chrome.

Expected Outcomes: 
	I am expecting to produce a robust and easy-to-use application that is useful for current Anki users. The UI should be easily explainable. I am not currently trying to implement any AI portions as this takes more work than this semester allows for (read part 2 for more information). The "basic card" should be implemented, allowing the user to create a card to a specific deck

Current Progress:
	As I am making this project now, I have been able to use Google's Side Panel API, which has added a much needed feature to this development. Comparing this to current options makes this extension easier and better to use because of its simplicity and availability across any website (unlike other extensions that close after not being clicked on, or may be too persistent to take the specific "X" to close and stop covering information). Current UI status can be seen below. Tracking the cards into the right deck is posing a challenge as using the AnkiConnect API is new to me, but I should be able to get that straightened out. Utilizing the AnkiConnect API's also takes the burden off how I am meant to transport the created card to the user's specific account. All of the basic expected outcomes seem to be obtainable within the desired deadline, and with a interest in using this project personally, the future work also seems attainable within a year's work of time. 









Part 2: Future Work
__________________________________________________________
Currently, I am trying to add space for growth of this extension that would allow for the integration of AI. I am not talking about basic GPT-4 inclusion as this may make it harder for the user to use rather than easier. The main idea I desire to create for the AI models I want to allow for are actually an array of models. Based on the desired topic, the user should be able to work with an assistant AI. This AI should also work as a web-scraper, taking into account other decks that are posted on AnkiWeb(https://ankiweb.net/shared/decks), but also all across the internet, such as on Reddit or AnkiPro. By having multiple specific models, this would reduce the load on each model as it knows the best sites to browse, be able to unpack the apkg files, and recommend relevant cards from these decks. 
An example of the complexity that these models should be able to tackle would be in this scenario:
A medical school student is trying to make a deck really quickly. There are many decks online, but most go over too much information, and making cards by hand takes too long. Utilizing this extension, the medical school student should be able to customize select cards given from all over the web, all recommended by the AI assistant due to the few cards she already made or an input she has given.
